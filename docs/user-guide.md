# Hero Forge User Guide

This guide explains the intended user flow for building a superhero in Hero Forge Workshop.

## Goal

Build an original hero from one origin source and a focused set of powers:

- Origin: how the hero got powers
- Primary: the signature power
- Secondary: supporting combo powers
- Utility: practical field-use power
- Derived limits: drawbacks pulled from the selected powers and optional story constraint text

## Build Flow

### 1. Choose An Origin

Origin is not a power. It is the cause of the hero's powers.

Examples:

- Mutation / Gene
- Accident
- Bite / Infection
- Experiment
- Artifact / Relic
- Cosmic Event
- Magic / Pact
- Training
- Tech Upgrade
- Alien / Species
- Dimensional Contact

The selected origin biases the library toward fitting categories. It should not hard-lock the user out of other powers.

### 2. Pick A Primary Power

Primary is the hero's signature. It is the power people remember when they describe the character.

Good Primary powers are usually:

- high offense
- high control
- concept-defining
- central to the hero's name and role
- strong enough to anchor the story

Broad Primary powers, such as reality, time, force, gravity, dimensional, or probability powers, need stronger drawbacks or story constraints.

### 3. Add Secondary Powers

Secondary powers support the primary power without replacing it. A hero can have up to three.

Good Secondary powers usually:

- create combos with the primary
- cover one weakness
- explain a tactical style
- add flavor without making the hero unreadable

Avoid turning secondary powers into an unrelated inventory. If the kit cannot be explained in one sentence, the build is probably too loose.

### 4. Add Utility

Utility is for field use.

Examples:

- movement
- rescue
- scouting
- defense
- investigation
- stealth
- communication
- escape

Utility makes the hero usable outside a direct fight.

### 5. Review The Draft

Use the Hero Forge panel to review:

- generated hero name
- classification
- stats
- strengths
- derived limits
- build quality
- synergy notes
- conflicts
- story brief
- export sheet

The draft is incomplete until it has at least:

- origin
- primary
- one support power, either secondary or utility
- readable limitation from weaknesses or story constraint

## Filters

Use filters to narrow the large library:

| Filter | Use |
| --- | --- |
| Search | Find by name, tag, strength, weakness, or description |
| Category | Browse broad power family |
| Subcategory | Narrow within a category, such as teleportation inside Mobility |
| Source | Show canon, imported, or all powers |
| Slot fit | Show powers recommended for Primary, Secondary, or Utility |
| Tier | Core, Advanced, Legendary |
| Stat filters | Minimum offense, defense, mobility, utility, control; maximum risk |
| Sort | Recommended, balance, popularity, risk, stat high, A-Z |

## Review Mode

Review mode shows selected powers even if the current search or filter would normally hide them. Use this when checking the current build path from the right-side panel.

## Compare Tray

Use the compare tray when multiple powers look similar. Compare up to four powers, then assign the best one to the active slot.

## Save And Export

Saved drafts are stored locally in the browser. Export text is generated from the current draft and can be copied from the Hero Forge panel.

## Common Mistakes

| Mistake | Fix |
| --- | --- |
| Treating origin as a power | Pick origin from the origin picker, then assign powers separately |
| Adding a broad Primary with no cost | Add a story constraint or choose support powers that expose limits |
| Picking only attack powers | Add utility for field use |
| Picking unrelated secondary powers | Replace them with powers that explain the same combat or story concept |
| Looking for a limitation filter | Limitations are derived from weaknesses; they are not a separate filter |
