# Data Dictionary

This document defines the app's major data shapes. It should stay aligned with `src/data/superpowers.js`, `src/utils/powerLibrary.js`, and `src/utils/heroBuilder.js`.

## Canon Category

Defined in `POWER_CATEGORIES`.

| Field | Type | Meaning |
| --- | --- | --- |
| `id` | string | Stable category key, such as `physical` or `psychic` |
| `name` | string | Human-readable label |
| `tagline` | string | Short explanation used in UI and docs |
| `accent` | string | Hex color used for category styling |

## Canon Power

Defined in `BASE_SUPERPOWERS`.

| Field | Type | Meaning |
| --- | --- | --- |
| `id` | string | Stable canon power key |
| `name` | string | Power name |
| `category` | string | Category ID from `POWER_CATEGORIES` |
| `tier` | `core` \| `advanced` \| `legendary` | Authored complexity/power tier |
| `role` | string | Narrative/combat role label |
| `description` | string | Full power description |
| `strengths` | string[] | Benefits surfaced in draft review |
| `weaknesses` | string[] | Drawbacks used as derived limits |
| `counters` | string[] | Counterplay examples |
| `stats` | object | Authored 1-10 stat block |

## Imported Power

Generated by `scripts/import-superpower-list.mjs` into `public/data/superpower-list-pool.json`.

| Field | Type | Meaning |
| --- | --- | --- |
| `sourceId` | number | Original Superpower List ID |
| `name` | string | Imported power name |
| `overview` | string | Short source overview |
| `description` | string | Longer source description |
| `pros` | string[] | Source-listed benefits |
| `cons` | string[] | Source-listed drawbacks |
| `tags` | string[] | Source tags |
| `state` | string | Publication state; only `published` loads into the app |
| `preferenceRatio` | number | Community comparison ratio |
| `timesPreferred` | number | Times this power won a comparison |
| `timesRejected` | number | Times this power lost a comparison |
| `totalComparisons` | number | Total comparisons |
| `createdAt` | string | Source timestamp |
| `updatedAt` | string | Source timestamp |
| `lastComparedAt` | string | Source timestamp |
| `username` | string | Source author username |

## Unified Power

Created by `normalizeCanonPower()` and `normalizeImportedPower()`. The UI should consume this shape instead of raw source records.

| Field | Type | Meaning |
| --- | --- | --- |
| `id` | string | Global ID with source prefix, such as `canon:flight` |
| `source` | `canon` \| `imported` \| `generated` | Data origin |
| `name` | string | Display name |
| `category` | string | Category ID |
| `categoryId` | string | Category ID duplicate for selection compatibility |
| `categoryName` | string | Human-readable category |
| `categoryAccent` | string | Category color |
| `tier` | `core` \| `advanced` \| `legendary` | Authored or inferred tier |
| `role` | string | Authored or inferred role |
| `description` | string | Full description |
| `summary` | string | Short card summary |
| `strengths` | string[] | Benefits |
| `weaknesses` | string[] | Drawbacks |
| `counters` | string[] | Counterplay examples |
| `tags` | string[] | Search/filter metadata |
| `stats` | object | 1-10 stat block |
| `score` | number | Internal deterministic sort score |
| `popularity` | number | Canon-derived or imported preference ratio |
| `raw` | object | Original source payload |

## Ranking Profile

Target enriched ranking profile. This field is optional during rollout; the app must fall back to top-level `tier`, `stats`, `score`, and recommendation helpers when it is missing.

| Field | Type | Meaning |
| --- | --- | --- |
| `rating` | `core` \| `advanced` \| `legendary` | User-facing power rating label |
| `scope` | `focused` \| `versatile` \| `expansive` | How broad or story-breaking the power is |
| `riskLevel` | `low` \| `medium` \| `high` \| `extreme` | Readable risk band |
| `bestRole` | `primary` \| `secondary` \| `utility` | Best slot fit before origin bias |
| `confidence` | `low-data` \| `inferred` \| `strong` | Trust level for inferred ranking metadata |
| `popularityLabel` | `known-pick` \| `niche-pick` \| `unproven` \| null | Imported comparison activity label |
| `sortScore` | number | Internal balanced sort value only |
| `evidence` | object | Matched signals used to produce labels |

Use `ranking.rating`, not `ranking.tier`. Top-level `tier` remains for compatibility with current cards, filters, and existing tests.

## Stats

| Field | Range | Meaning |
| --- | ---: | --- |
| `offense` | 1-10 | Damage, direct threat, or combat pressure |
| `defense` | 1-10 | Durability, protection, mitigation |
| `mobility` | 1-10 | Movement, repositioning, access |
| `utility` | 1-10 | Rescue, scouting, investigation, support, field use |
| `control` | 1-10 | Precision, containment, manipulation, battlefield control |
| `risk` | 1-10 | Collateral, narrative, moral, or balance risk |

## Origin Source

Defined in `ORIGIN_SOURCES`.

| Field | Type | Meaning |
| --- | --- | --- |
| `id` | string | Stable origin key |
| `name` | string | Display label |
| `categoryId` | string | Primary category affinity |
| `preferredCategories` | string[] | Categories boosted by origin fit |
| `summary` | string | Short explanation |
| `storySeed` | string | Story prompt used in draft generation |

## Origin Selection

Created by `createOriginSource()`.

| Field | Type | Meaning |
| --- | --- | --- |
| `id` | string | `origin:${originId}` |
| `selectionId` | string | Stable selection key |
| `source` | `origin` | Marks this as an origin, not a power |
| `name` | string | Origin label |
| `categoryName` | `Origin Source` | Fixed grouping label |
| `preferredCategories` | string[] | Recommendation bias categories |
| `summary` | string | Origin summary |
| `storySeed` | string | Story prompt |

## Hero Build

Created by `createEmptyHeroBuild()` and updated by assignment/profile actions.

| Field | Type | Meaning |
| --- | --- | --- |
| `alias` | string | User-selected hero name override |
| `civilianName` | string | Civilian identity |
| `homeBase` | string | Operating location |
| `motivation` | string | Why the hero keeps acting |
| `storyConstraint` | string | Optional custom cost/rule/range/cooldown/limit |
| `origin` | OriginSelection \| null | How powers were gained |
| `primary` | Selection \| null | Signature power |
| `secondary` | Selection[] | Up to three support powers |
| `utility` | Selection \| null | One field-use power |
| `limitation` | null | Backward compatibility only; new UI should not assign this |

## Selection

Created by `toSelection()`.

| Field | Type | Meaning |
| --- | --- | --- |
| `selectionId` | string | ID used for assignment/removal |
| `id` | string | Unified power ID |
| `source` | string | `canon` or `imported` |
| `name` | string | Power name |
| `category` | string | Display category name |
| `categoryId` | string | Category ID |
| `summary` | string | Short description |
| `strengths` | string[] | Benefits |
| `weaknesses` | string[] | Derived limits |
| `tags` | string[] | Tags |
| `stats` | object | Stat block |
| `score` | number | Internal sort score |
| `popularity` | number | Ranking signal |

## Hero Draft

Created by `buildHeroDraft()`.

| Field | Meaning |
| --- | --- |
| `heroName` | Final displayed name |
| `generatedName` | Deterministic fallback name |
| `nameOptions` | Alternate generated aliases |
| `nameRationale` | Why the generated name fits |
| `classification` | Role archetype |
| `selectedCount` | Count of selected powers |
| `filledSlots` | Completed origin/power steps |
| `canonCount` / `importedCount` | Source mix |
| `stats` | Aggregate stat block |
| `strengths` | Combined strengths |
| `weaknesses` | Combined weaknesses and derived limits |
| `tags` | Combined tags |
| `synergy` | Score, notes, conflicts |
| `recommendations` | Next actions |
| `checklist` | Build-path steps |
| `quality` | Identity, field use, balance, cohesion metrics |
| `characterSheet` | Export-ready profile |
| `storyBrief` | Premise, arc, beats |
