# Hero Forge Workshop Ranking Refactor Handoff

This zip is a Codex-ready markdown handoff for the Hero Forge Workshop ranking and power-library refactor.

## What this handoff is for

Use these notes to implement the ranking improvement without turning imported powers into fake objective numeric rankings.

The desired outcome is:

1. Numeric scores still exist internally for deterministic sorting.
2. The UI stops showing raw values like `Score 23` as if they are true universal rankings.
3. Each power gets readable labels: rating, scope, risk level, best role, confidence, and popularity label.
4. Imported ranking metadata is generated by a deterministic enrichment pipeline.
5. The app loads enriched JSON instead of recalculating all ranking metadata live.

## Highest-priority implementation decisions

1. Use `ranking.rating`, not `ranking.tier`, for the new ranking profile.
2. Keep top-level `tier` for backward compatibility with existing code.
3. Keep top-level `score` or `ranking.sortScore` internal only.
4. Split popularity from confidence. They are related but not the same signal.
5. Treat `power.ranking` as optional during rollout so rollback is simple.
